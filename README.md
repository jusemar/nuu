# Nooo

Plataforma completa de e-commerce desenvolvida para operação de lojas virtuais, reunindo catálogo, produtos, autenticação, frete, integrações, automações e recursos de Inteligência Artificial.

🌐 https://nooo.com.br

## Sobre o projeto

O Nooo é uma plataforma de e-commerce desenvolvida como um produto real e publicada em produção.

O projeto envolve diferentes áreas do desenvolvimento full stack, incluindo experiência de compra, administração de produtos, autenticação, logística, integrações externas e recursos de atendimento.

## Principais recursos

- Catálogo e gestão de produtos
- Categorias e busca de produtos
- Páginas de produtos e carrinho
- Autenticação e recuperação de senha
- Gestão de conteúdo
- Integrações via API
- Integrações de frete e logística
- Recursos de atendimento com IA
- Automações para operação do e-commerce
- Interfaces responsivas

## Tecnologias

- Next.js
- React
- TypeScript
- Node.js
- PostgreSQL
- Drizzle ORM
- Tailwind CSS
- APIs REST
- Git

## Desenvolvimento assistido por IA

Inteligência Artificial é utilizada como ferramenta ativa de apoio ao desenvolvimento, auxiliando no planejamento, implementação, testes, análise de problemas, revisão e evolução das funcionalidades.

O projeto também utiliza recursos de IA aplicados à experiência e operação da plataforma.

## Status

Projeto em desenvolvimento contínuo e publicado em produção.
